# ARNI GAME — «Побег из города»

Браузерный 3D-раннер для Telegram-канала. Игрок управляет маскотом ARNI, который убегает от летающего дрона-охранника по неоновому вечернему городу. **Бесконечный забег** (с 26.11.2026): цель — убежать как можно дальше, набрать очки и побить рекорд.

- **Игра:** https://artyuschenko26.github.io/arni-game/
- **Мини-приложение в Telegram:** https://t.me/arnigame_bot/arnigame_play (бот `@arnigame_bot`)
- **Хостинг:** GitHub Pages из ветки `main`, корень репозитория. Публикация происходит сама после каждого коммита (вкладка Actions → `pages build and deployment`, 1–2 минуты).

## Правила проекта (обязательно для любого разработчика или ИИ)

1. **Не переписывать проект с нуля.** Только небольшие, проверяемые изменения поверх текущего кода.
2. **Не ломать и не удалять работающие механики.** Перед изменением проверить, на что оно влияет.
3. **Маскот ARNI неизменен.** Эталоны — `assets/arni_main.webp` (основной), `assets/arni_victory.webp` и `assets/arni_thumbs.webp` (допустимые позы). Запрещено менять лицо и черты внешности, причёску и цвет волос, пропорции тела и головы, чёрное худи с оранжевыми элементами и логотипом ARNI, брюки, обувь и общий стиль 3D-персонажа. Разрешено менять позу, эмоции и положение рук. Оранжевая буква «A» на спине худи согласована владельцем.
4. **Стиль чёрно-оранжевый,** неоновый вечерний город. Визуальный ориентир — макет владельца (последний утверждённый вид игры).
5. **Мобильный формат прежде всего.** Управление только свайпами по всему экрану, кнопок управления нет. Игра должна быть удобной внутри Telegram на телефоне и не тормозить на средних устройствах (никакой тяжёлой постобработки).
6. **Режим — бесконечный раннер** в духе жанра (как Subway Surfers), но **без копирования** чужих механик, персонажей и стиля: свои механики, свой мир и персонаж. Прежний режим уровня с финишем на 1000 м сохранён в коде (`MODE='level'`), его не удалять.
7. **Перед загрузкой своей версии сверяться с репозиторием.** Если файл в репозитории менялся из другого места, сначала совместить изменения, иначе одна правка молча затрёт другую.

## Как устроен проект

| Файл | Что внутри |
|---|---|
| `index.html` | Вся игра в одном файле: разметка и стили интерфейса, код на Three.js 0.160 (грузится с jsDelivr, запасной CDN — unpkg) |
| `assets/arni_*.webp` | Эталонные изображения ARNI с вырезанным фоном (меню, пауза, победа, поражение) |
| `assets/neon_lion.webp` | Неоновая вывеска «ARNI GAME» со львом (для стены дома) |

Сборки нет: достаточно отредактировать `index.html` и закоммитить.

### Основные части кода (в порядке следования в `index.html`)

- **Сцена и город:** небо по районам (`SKY`, `setZoneLook`), свечение-спрайты (`glow`, `GLOW`), отражения на асфальте (`streak`), фактура асфальта, тротуары и бордюры, дома с окнами, витринами, неоновыми вывесками, деталями фасадов, щитом с портретом ARNI и вывеской со львом, изогнутые фонари с деревьями в кадках и столбиками (`lamps`), мост со стрелками (`bridges`), неоновая башня, небоскрёбы и луна на горизонте.
- **ARNI:** процедурная 3D-модель по эталону (раздел «ARNI — 3D-модель по утверждённому эталону»). Узлы анимации: `player`, `head`, `armL/armR`, `elbowL/elbowR`, `legL/legR`, `kneeL/kneeR`, `eyeWhites` (моргание). Модель целиком масштабирована группой `rig` (×1.22).
- **Дрон-охранник:** `makeRobot()` — корпус, визор, 4 винта (`userData.rotors`), мигалка, прожектор. Летит за ARNI; расстояние зависит от «отрыва» (`robotZ(lead)`).
- **Препятствия:** шаблоны в `obTemplate(type)`: `car`, `box`, `barrier` (перепрыгнуть), `beam` (проскользнуть). `makeObstacle` — препятствие в одной полосе, `makeFull` — во всю ширину дороги.
- **Монеты:** `makeCoin`, `coinRow` — светящиеся оранжевые кольца.
- **Режим:** `MODE='endless'` (основной) или `'level'` (старый уровень на 1000 м с финишем и звёздами — выключен, но сохранён).
- **Бесконечный забег:** обучение на старте (`TUT`, первые ~105 м, подсказки в первых трёх забегах), дальше `spawnPattern()`. Районы идут по кругу по `ZONE_LEN = 500` м: улицы → стройка → техноквартал (`zoneOf`); каждый новый круг (`loopOf`) сокращает интервалы между препятствиями. Скорость растёт с дистанцией (до 40). Свободный проход есть всегда. Придорожные декорации бесконечно переиспользуются.
- **Погоня:** первое столкновение — дрон подлетает вплотную (`lead≈4.5`), второе, пока он рядом (`lead<12`), — поимка. Без ошибок дрон постепенно отстаёт до `lead=20`.
- **Очки:** дистанция × множитель (`mult` x1…x5, растёт каждые 250 м без столкновений, сбрасывается при ударе) + 10 очков за монету в конце. Рекорд — `arni_best_score` в `localStorage`.
- **Финиш (только `MODE='level'`):** ворота на `FIN = 1000` м, `beginFinish()` → сцена победы → `finish(true)`.
- **Итоги:** очки, «Новый рекорд!», дистанция, монеты; кнопка «Поделиться» (`shareResult`, ссылка `SHARE_URL`) с текстом про очки.
- **Управление:** свайпы по холсту (`pointerdown`/`pointermove` — срабатывают во время движения пальца), клавиатура (стрелки, WASD, Space, Shift, Esc/P — пауза).
- **Telegram:** `initTelegram()` — `ready`, `expand`, `disableVerticalSwipes`, цвета шапки, автопауза при сворачивании; `haptic()` — вибрация.
- **Камера:** `fitCamera()` подстраивает дистанцию под ширину экрана, чтобы на узких телефонах все три полосы были в кадре.
- **Цикл:** `animate()` — состояния `menu`, `run`, `countdown` (3-2-1 после паузы), `paused`, `finishing`, `end`.

Важно: координата `1 м дистанции = 1/0.62 единиц сцены` (`WU`). Объекты на дороге сдвигаются на `speed*dt` за кадр, дистанция растёт на `speed*dt*0.62`.

## Текущее состояние (25.11.2026)

Бесконечный режим: районы по кругу, растущая скорость и сложность, очки с множителем, погоня «два удара — поимка», рекорд очков. Обучение, пауза, свайпы, Telegram, графика по макету — как раньше. Автопилот проходит 1200+ м без столкновений.

**Следующий шаг (согласован):** свои бонусы — «Капюшон» (одно столкновение прощается), «ЭМИ-импульс» (дрон глохнет и отстаёт), «Разгон» (рывок с неуязвимостью и сбором монет), возможно магнит монет.

## Известные ограничения и идеи

- 3D-модель ARNI — упрощённая «игрушечная» версия эталона. Для точности уровня эталона нужна готовая модель `.glb` (например, из Meshy: Image to 3D → авто-скелет → анимации Running, Jump, Victory). Её можно встроить через `GLTFLoader`, оставив текущую модель запасной.
- Плавность проверялась только в эмуляции; на реальных телефонах нужна проверка. При тормозах — сделать облегчённый режим (меньше свечения и теней, ниже разрешение).
- Отражения на асфальте и свечение «нарисованы» спрайтами (без постобработки) — это сознательный выбор ради телефонов.

## Как проверять изменения

1. Открыть игру локально через веб-сервер (не как файл, иначе не загрузятся текстуры): `python3 -m http.server` в папке проекта → `http://localhost:8000`.
2. В браузере включить эмуляцию телефона (например, 390×844) и проверить: старт, свайпы во все стороны, прыжок, скольжение, паузу, поимку, финиш, экран итогов, консоль без ошибок.
3. После коммита подождать публикацию на GitHub Pages и проверить живую ссылку и мини-приложение в Telegram.
